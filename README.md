Clements Design front-end recreation.

Open index.html directly in a browser. No server is required.
Pages: index.html, press.html, contact.html.

IMPORTANT: Images are loaded from the original Squarespace CDN and require an internet connection. The actual image files are NOT included in this ZIP. If the original CDN blocks or removes them, images may not appear.

The JavaScript image manifest is embedded directly in script.js to avoid file:// fetch restrictions.
